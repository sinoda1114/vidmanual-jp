# VidManual (AI Video-to-Manual Generator)

VidManualは、画面録画や操作動画をアップロードするだけで、AIが自動的にステップバイステップの手順書（操作マニュアル）を生成するWebアプリケーションです。

Google Gemini 3 Flashモデルを活用し、動画内の音声と視覚情報を解析。適切なタイミングでスクリーンショットを自動抽出し、説明文とセットにしてWordドキュメント(.docx)として出力します。

## ✨ 主な機能

*   **動画から自動生成**: 動画ファイル（MP4, MOV, WebM, AVI）をドラッグ＆ドロップするだけで解析を開始。
*   **スマートキャプチャ**: 手順ごとに最適な瞬間をAIが特定し、ブラウザ上で高画質なスクリーンショットを自動抽出します。
*   **インタラクティブな編集**:
    *   タイトルや説明文の編集
    *   手順の並べ替え、削除、追加
    *   **ドラッグ＆ドロップ画像差し替え**: プレビュー動画の特定のフレームをドラッグして、手順の画像を直感的に差し替えることができます。
*   **多言語翻訳**: 作成したマニュアルをワンクリックで英語、中国語、韓国語、スペイン語などに翻訳・複製できます。
*   **Wordエクスポート**: フォーマット済みの `.docx` ファイルとしてダウンロードできます（全言語一括ZIPダウンロード対応）。

## 🛠 技術スタック

*   **Frontend**: React 19, TypeScript, Tailwind CSS
*   **AI / ML**: Google Gemini API (`@google/genai` SDK)
    *   Model: `gemini-3-flash-preview`
*   **Document Generation**: docx
*   **UI Components**: Lucide React

## 🚀 セットアップと実行

このプロジェクトを実行するには、Google Gemini APIキーが必要です。

### 前提条件

*   Node.js (v18以上推奨)
*   Google Cloud ProjectでのGemini APIキーの取得

### インストール

1.  リポジトリをクローンします
    ```bash
    git clone https://github.com/your-username/vidmanual.git
    cd vidmanual
    ```

2.  依存パッケージをインストールします
    ```bash
    npm install
    ```

3.  環境変数を設定します
    プロジェクトのルートに `.env` ファイルを作成するか、環境変数としてAPIキーを設定してください。
    ```env
    API_KEY=your_gemini_api_key_here
    ```

4.  開発サーバーを起動します
    ```bash
    npm start
    ```
    ブラウザで `http://localhost:1234` (または表示されるURL) にアクセスしてください。

## 📖 使い方

1.  **アップロード**: トップ画面に動画ファイルをドラッグ＆ドロップします。
2.  **解析待機**: AIが動画を解析し、マニュアルを生成するのを待ちます（数秒〜数分）。
3.  **編集**: 生成されたマニュアルを確認します。
    *   必要に応じてテキストを修正します。
    *   動画プレイヤーの「フレームをドラッグ」ハンドルを使って、スクリーンショットをベストな瞬間に差し替えます。
    *   「＋」タブから他の言語へ翻訳を追加できます。
4.  **保存**: 「Word(.docx)保存」ボタンをクリックしてファイルをダウンロードします。

## ⚠️ 注意事項

*   このアプリはブラウザのCanvas APIを使用して動画から画像を抽出するため、ローカルで処理が完結する部分と、APIに動画データを送信する部分があります。
*   動画の長さやAPIの制限により、処理に時間がかかる場合があります。
